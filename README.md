# 投資結算管理中心

這是一套可在 Windows 本機執行、也可由 GitHub Pages 線上開啟的投資資料與到期收益結算系統。管理者可以手動新增或由 Excel 匯入投資資料，系統會自動計算到期日，並一次結算所有已到期顧客的淨收益。

## 主要功能

- 一筆投資資料包含：投資人名、投資案名、投資金額、開始時間、持續時間、投資利率、投資淨收益與備註。
- 尚未結算的資料可以編輯或刪除；已結算資料會鎖定，避免歷史被改寫。
- 支援 `.xlsx`、`.xls` 拖曳或選檔匯入，會先自動辨識欄位、逐列驗證並預覽。
- 重複資料會安全略過；有任何格式錯誤時不會部分匯入。
- 一鍵找出基準日前所有到期且尚未結算的投資，建立同一批次的不可變快照。
- 結算總表依顧客彙整本金、加權利率、淨收益與有效報酬率。
- 點擊顧客名稱可查看目前批次、完整歷史時間戳，以及每個投資案的本金、利率與獲利。
- 結算報表可匯出 Excel；完整資料可匯出／還原 JSON 備份。

## Windows 一鍵啟動

需求：Node.js 22.5 以上版本。

1. 雙擊 `start-local.cmd`。
2. 系統會開啟 `http://127.0.0.1:4173/admin.html`。
3. 保持命令視窗開啟；完成後按 `Ctrl+C` 停止系統。

也可以在終端機執行：

```powershell
npm start
```

伺服器只綁定 `127.0.0.1`，外部網路無法直接連入。本機資料寫入：

```text
data/investment-manager.db
```

SQLite 資料檔已列入 `.gitignore`，不會意外提交到公開 repository。建議每次大量匯入或結算後，在「備份與設定」下載完整備份。

## 手動新增與結算規則

- 持續時間支援「日」或「月」。月期間會依日曆計算；例如 1 月 31 日加 1 個月會落在 2 月最後一天。
- 投資利率是整期百分比，輸入 `5` 代表 `5%`。
- 投資淨收益是結算的權威金額，可為 `0` 或負數；系統只把「本金 × 利率」當成核對提示，不會覆蓋輸入的淨收益。
- 到期條件：`到期日 <= 結算基準日` 且尚未結算。
- 一鍵結算只彙整淨收益；本金另列參考，不會被誤標成已撥款金額。
- 同一顧客、同一投資案可以有多筆獨立投資，結算時都會逐筆保留。
- 結算完成後，顧客與投資案名稱、本金、開始／到期日、利率、淨收益與結算時間戳都會保存在快照中。

## Excel 匯入格式

在「Excel 匯入」點擊「下載 Excel 範本」可取得標準檔案。必要欄位：

| 欄位 | 範例 | 說明 |
|---|---:|---|
| 投資人名 | 王小明 | 可使用既有名稱或建立新投資人 |
| 投資案名 | 設備租賃 A | 可使用既有名稱或建立新投資案 |
| 投資金額 | 500000 | 必須大於 0 |
| 開始時間 | 2026-08-01 | 支援 Excel 日期與常見日期文字 |
| 持續時間 | 6個月 | 也可填 `180天`；純數字預設為月 |
| 投資利率(%) | 5 | 可填 `5`、`5%` 或 Excel 百分比格式 |
| 投資淨收益 | 25000 | 可為 0 或負數 |
| 備註 | 合約編號 A01 | 選填 |

系統會在前 20 列自動尋找表頭，並選擇第一張符合必要欄位的工作表。匯入前會顯示可匯入、重複略過與格式錯誤筆數。

## 開發與測試

不需要安裝 npm 套件；本機伺服器使用 Node 內建 HTTP 與 SQLite。

```powershell
npm test
npm run start:no-open
```

核心測試涵蓋月底／閏年日期、到期邊界、空白欄位、零或負收益、同顧客同案多筆投資、重複結算防護與本金加權利率。

## 線上瀏覽器模式

公開網址：<https://xieyaozhong.github.io/CASE1-15000/>

由 GitHub Pages 開啟時，系統會自動使用瀏覽器 localStorage，手動新增、Excel 匯入、編輯、一鍵結算、顧客歷史與報表匯出都可操作。投資資料只存在目前瀏覽器，不會寫入公開 repository，也不會在不同裝置間同步；請定期在「備份與設定」下載 JSON 備份。

需要 SQLite 持久化時，請由 `start-local.cmd` 啟動，狀態列會顯示「本機 SQLite」。
